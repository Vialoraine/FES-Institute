Intro to CSS

What is CSS

  • Stands for Cascading Stylesheets
  • Used to style websites

Methods for adding CSS

There are three methods for adding CSS

  • Inline CSS

    • Style directly in the HTML element

  • Internal CSS

    • Using style tags within an HTML file

  • External CSS (recommended)

    • Linking an external CSS file

Common Properties

Examples:

  • color: sets the color of the text
  • background-color
  • width
  • height
  • border
  • fonts-size, font-weight, font-family

Color in CSS

3 ways to set color

  • Words: red, green, blue, cyan
  • rgb(0, 255, 0) -> green
  • Hex: #ff0000 -> red
