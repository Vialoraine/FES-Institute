Height: Best Practices

You want to avoid hardcoding a height value because it will affect web page responsiveness.

In the example, when hardcoding a height value: when displaying on a smaller window or device, the text extends past the background color of the div.

Better practice is instead of hardcoding a height value using a px value is to use vh. Vh is short for viewport height, where 1vh equals 1% of the visible browser window's height. Using 100vh forces an element (like a header or background) to take up exactly 100% of the screen height, regardless of the device.
