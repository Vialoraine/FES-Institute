Intro to CSS

What is CSS

    • Style directly in the HTML element

  • Internal CSS

  • External CSS (recommended)

    • Linking an external CSS file

Common Properties

Examples:

  • color: sets the color of the text
  • background-color: sets the background-color of the element
  • width: sets the width of the element
  • height: sets the height of the element
  • border: sets a border around the element
  • fonts-size, font-weight, font-family

Height: Best Practices

You want to avoid hardcoding a height value because it will affect web page responsiveness.

In the example, when hardcoding a height value: when displaying on a smaller window or device, the text extends past the background color of the div.

Better practice is instead of hardcoding a height value using a px value is to use vh. Vh is short for viewport height, where 1vh equals 1% of the visible browser window's height. Using 100vh forces an element (like a header or background) to take up exactly 100% of the screen height, regardless of the device.

Color in CSS

3 ways to set color

  • rgb(0, 255, 0) -> green
  • Hex: #ff0000 -> red

Specificity

Specificity is the prioritization of styling

  • class: multiple elements
  • id: single element or sections

CSS Hierarchy

  1. id
  2. class
  3. element

Best practice is to use ids for sections.

Box Model

What is the box model?

A container that consists of multiple different CSS properties

What does it consist of?

  • content
  • padding
  • border
  • margin

Best Practice:

  1. Margin to seperate elements
  2. Padding to increase spacing

Complex Properties

  • display
  • position

Display

Two CSS display values

  • Block: takes 100% of the width, startss on a new line
  • examples: p and div
  • Inline: doesn't allow you to set width and height, starts on the same line.
  • examples: span and img

Postition

CSS position values

Common

  • Static: follows normal flow of page
  • Relative: follows normal flow of page, lets you position: top, right, bottom, left
  • Absolute: doesn't follow normal flow of page, lets you position: top, right, bottom, left. position based off closest 'position: relative' parent.

Uncommon

  • Fixed: sticks element permanently, allows top, right, bottom, left positioning
  • Sticky: sticks element permanently on page once it hits a threshold
