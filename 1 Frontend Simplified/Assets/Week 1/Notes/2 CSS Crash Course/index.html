Common Properties

Examples:

  • color: sets the color of the text
  • background-color: sets the background-color of the element
  • width: sets the width of the element
  • height: sets the height of the element
  • border: sets a border around the element
  • fonts-size, font-weight, font-family

Height: Best Practices

You want to avoid hardcoding a height value because it will affect web page responsiveness.

In the example, when hardcoding a height value: when displaying on a smaller window or device, the text extends past the background color of the div.

Better practice is instead of hardcoding a height value using a px value is to use vh. Vh is short for viewport height, where 1vh equals 1% of the visible browser window's height. Using 100vh forces an element (like a header or background) to take up exactly 100% of the screen height, regardless of the device.

Complex Properties

  • display
  • position

Display

Two CSS display values

  • Block: takes 100% of the width, startss on a new line
  • examples: p and div
  • Inline: doesn't allow you to set width and height, starts on the same line.
  • examples: span and img

Postition

CSS position values

Common

  • Static: follows normal flow of page
  • Relative: follows normal flow of page, lets you position: top, right, bottom, left
  • Absolute: doesn't follow normal flow of page, lets you position: top, right, bottom, left. position based off closest 'position: relative' parent.

Uncommon

  • Fixed: sticks element permanently, allows top, right, bottom, left positioning
  • Sticky: sticks element permanently on page once it hits a threshold

Media Queries

What are they used for? used to make a page more responsive

Common Breakpoints (max-width)

  • 576px: mobile phones
  • 768px: tablets
  • 992px: desktops
  • 1200px: large desktops

Example: (style.css)

@media (max-width: 992px){ div{ font-size: 20px; } }

CSS Transitions and Transforms

When used together, they allow us to create simple animations and add valuable interaction and visual feedback for the user. Transforms move or change the appearance of an element while transitions make the element smoothly and gradually change from one state to another.

There are two properties required in order for the transition to take place

  1. transition-property
  2. transition-duration

Transition Shorthand (the first two properties are required)

div { transition: property duration timing-function delay; }

  • Property: Specifies the CSS property where the transition will be applied. You can a=pply a transition to an individual property (ie background-color or transform) or to all properties in the ruleset (all).
  • Duration: Timespan of the transition You can specify in seconds or milliseconds
  • Timing-Function: defines the speed of the transition over the duration. The default is ease which starts slow, quickly speeds up, and slows at the end. Other timing options include: linear, ease-in, ease-out, ease-in-out.

@keyframes: defines the element states at a specific timeframe

@keyframes popup{ 0% { transform: scale(1); } 50% { transform: scale(1.1); } 100% { transform: scale(1) } }

will animate to: pop upwards larger, to the user and back down to original size
