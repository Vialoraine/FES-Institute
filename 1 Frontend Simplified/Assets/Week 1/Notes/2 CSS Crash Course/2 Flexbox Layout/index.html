Flexbox Layout

1) justify-content

display: flex;

justify-content: _____

  • flex-start (default): items align to the left side of the container
  • flex-end: items align to right side of the container
  • center: items align to the center of the container
  • space-bottom: items display with equal spacing between them
  • space-around: items display with equal spacing around them

2) align-items

display: flex;

align-items: _____

  • flex-start: items align to the top of the container
  • flex-end: items align to the bottom of the container
  • center: items align at the vertical center of the container
  • baseline: items display at the baseline of the container
  • stretch: items are stretched to fit the container

Another property you can apply is align-self. It accepts the same values of align-items.

3) flex-direction

display: flex;

flex-direction: _____

  • row: items are placed the same as the text direction
  • row-reverse: items are placed opposite to the text direction
  • column: items are placed top to bottom
  • column-reverse: items are placed bottom to top

Sometimes reversing the row or colomn order of a container isn't enough.

In these cases, we can apply the order property to individual items. By default, items have a value of 0, but we can use this property to also set it to a positive or negative integer value (-2, -1, 0, 1, 2).

._____ { order: _____; }

4) flex-wrap

display: flex;

flex-wrap: _____

  • nowrap: every item is fit to a single line
  • wrap: items wrap around to additional lines
  • wrap-reverse: items wrap around to additional lines in reverse

5) flex-flow

display: flex;

flex-flow: _____

  • row wrap: items are placed in a row to additional lines
  • column wrap-reverse: items are in a column and opposite order

6) align-content

display: flex;

align-content: _____

  • flex-start: lines are packed at the top of the container
  • flex-end: lines are packed at the bottom of the container
  • center: lines are packed at the vertical center of the container
  • space-between: lines display with equal spacing between them
  • space-around: lines display with equal spacing around them
  • stretch: lines are stretched to fit the container

align-content: determines the spacing between the lines

align-items: determines how the items. as a whole, are aligned in the container

*when there is only one line, align-content has no effect
